# 金钱

## 1 10.21

这是我分析自己目前人生经历的第二个章节，被渲染的生存焦虑（或许也被表述为人民对美好生活的向往）可以说是目前最大的社会问题。而这其中欠缺的是物质生活还是精神生活，我认为很难评价。

但是我对钱的观念肯定是相当糟糕的，这是我会选择离职的另一个原因。

继续回想小时候的生活，可以用“穷”、“富有”、“知足”三个词来形容。“穷”指的是当时所处的物质水平，停电、买不了零食、可能两天一顿有肉；“富有”是针对于童年的经历与生活，可以说我处于我的老家尚有人烟走向荒废的过渡期，那时的河水尚且清澈，还能够摸鱼或者翻螃蟹；常见的野山还有人打理，能够留出一条条被踩出来或者镰刀割出来的土路，因此我们还会再老家的四处穿梭，还能在村里读上小学；“知足”是外婆经常对我说的一句话，大意是“对比某某家，每顿都有肉吃，你应该知足”，或许她便有所不知足，或者说村里的人都是如此。那时村里有人靠灰产（赌博）赚钱，我能够理解到那种嫉妒或者说闲聊时的氛围。

因为物质上的贫穷导致我从初中到大学都非常自卑，但现在我能理解到这是家长教育职责的缺失，而非真正的“物质贫穷”导致，当然这只是个人观点。当农村的小孩儿想要伸手去要一个玩具或者在一件玩具前站立良久时，他的家长会非常生气，然后用愤怒的语气让他跟着赶紧回家，当小孩表现得十分抗拒或者苦恼时（这种小孩儿的表现或许也是在家庭环境中训练得来），便更加生气并撇一根树枝边打边骂，像赶鸭子（或许他们会认为鸭子更听话）一样把小孩儿赶回家中。这其中最大的问题或许在于家长无法坦然接受自己很穷或者相对贫穷这个事实，在无力支付或者与自身意志违背时没有办法给出正确的行为反应。我在武汉生活的时期，同样能够观察到这种情形，或许因为这个城市也是这样又土又新吧，一边时高耸的超高层建筑，另一边是废弃脏乱的砖头屋。

这样的教育让我在金钱观念上没有办法去建立良好的逻辑认知——我能支付什么，或者说我能买什么。

我在金钱观念上完全没有得到任何的有效训练，我得到的只有这几种反馈：父母买不起，发脾气生气；咬咬牙买得起，认为可以买，“这不是钱的问题”，“你不用担心钱的问题”；“你还是节约一点，该花的地方就花，该节约的地方还是节约一点”。

在这种混乱又矛盾的表述之中会让我感到巨大的物质压力，但同时我又会把得到生活费的剩余部分投入到游戏之中，所以高中和大学期间一分钱也没有存下来。但同时我也不会买衣服或者鞋，这些就成了我该节约的地方。在高中或大学期间我会为此感到非常内疚，但是现在不会，我也不会为彼时没有储蓄习惯感到后悔，因为这里有涉及到另一个问题，从小学到高中，能够玩游戏都是我被设定的一套奖励机制；到了大学之后这套机制崩溃了......

开始工作之后，领到了自己的薪资，我也没有什么正确的金钱观念。在实习期间便开始在健身房锻炼，然后私教向我推销他的课程；接触各种类型的手游，充值、自建或者买号，玩一段时间弃坑（这应该是从大学期间就开始了）。薪资还是会剩下一点但不多，但后续就因为时间压力以及健身不断追加的成本导致我提出了第一次辞职。

我很难评价健身私教，他的性格比较外向，教授本身也很专业，实际上也没有对我有任何欺骗的行为，但是和他进行交流压力真的非常大。因为按照最开始的课程规划是一周两练（教学），其余时间自己练，然后会变成一周三练，就算我明确提出拒绝，也会被搪塞过去。

这也是为什么我不太愿意进行所谓“沟通”的原因，每个人都有自身的诉求，作为健身教练会面临非常大的业绩压力，自己还有小孩儿，所以会不断去尝试逼近客户的底线。

当时我接受了一周三练的请求，但是后来膝关节有些不是以及“扁平足”的问题，便又介绍了另外一位做康复的私教，因此一周变成了三练加两次康复。有时候会失眠，但是却已经很难提出休一天的请求（因为潜意识已经会认为没有用，或者说我很难拒绝，有很难违背这种他们单方面提出的约定），因为实际流程是他们率先提问。实在受不了了，所以我没有再回复他们的任何消息，也没有再去过那家对应的健身房。这对于我来说有些痛苦，因为辜负了他们的“期待”，虽然这只是当时我单方面的原则。

我认为他们是很好的私教，但是我完全无法应对这种性格，又或者说他们没有办法去接受“想要休息一天”这样的请求，因为公司的业绩设置与绩效考核会不断地榨取员工的剩余价值（当然，公司也有不得不如此的原因，毕竟场地、电力、设备折旧都需要成本）。私教的工作基本上是一个月休一天，只能说锻炼确实有好处。

那段时间我在公司的工作比较轻松，对AI的使用也基本停留在对代码问答或者Tabnine一类的代码自动填充工具。但是或许是因为健身的停止或者一些项目开发后没有成功的上架，我会感觉到“无聊”或者说“价值感缺失”。

最终没有成功离职，被劝说留了下来去做另一个项目。当然我在这里也得到了一个经验，依照我的性格的话，如果要选择拒绝别人，实际就是选择保持沉默；开口就已经意味着同意。

来到新的项目之后我会对项目有更全面的认知，能够从PostHog或者Adjust看到对应的用户行为分析或者收益分析，再此之前虽然也可以通过Mixpanel查看，但那时还没有那么留意。

好吧，其实那时就已经能够留意到Mixpanel的数据，每个月营收都在增长；但新项目可以说毫无盈利可言，偏向于探索性质。

也是在这期间我会用更多的时间关注“钱”的问题。

内心有一点愧疚感？因为我们的项目最终以失败告终。很难说我在这段经历中学到了什么或者什么都没有学到，毕竟这期间我的开发发生了这样的变化：
AI + 手写部分代码 -> Trae -> Cursor -> 非常短暂的Claude Code -> Codex -> 越来越强的Codex。AI越来越强，需要处理的任务也越来越多。虽然在使用Cursor时便不再手写代码，但是工作会越来越累，我自认为自己的专注度很高，八个小时的工作在手写代码时会有比较惬意，在用AI进行工作时认知过载。在单位时间内的需求越多，需要进行的需求拆分就会越多，随之而来的是每个需求的验收（后期已经不会看具体代码进行验收，只关注文件夹结构与代码块结构，更后期可能代码块结构也会被略过），然后针对每个需求出现的问题进行BUG修复。

这段工作期间，我会意识到对于时薪的计算，逐渐减少对于新手游的付费尝试，注意到企业成本的计算以及每个工作岗位的大致工作内容（这得益于我们公司扁平化的管理结构，不然我应该也看不了用户数据）。当然，我也注意到为什么我的工作（客户端开发）相对而言不那么“值钱”。

这不是一个技术问题。我们的公司大概会有这样一些位置：老板、项目经理、产品经理、运营、投放、美术、客户端开发、后端开发、中台、算法、人力资源，但后续会把客户端开发、后端开发、中台、算法统称为研发，而实际上也是在通过AI的使用后，多数需求侧的研发工作可以由一个人完成。

站在我的角度（分析我所处的公司），最影响项目是否赚钱的是产品经理和投放这两个职务。但产品经理的部分职务会同时其它所有（除开人力资源外）的职务瓜分，老板和项目经理最终会对项目形态有比较大的主导权；投放决定了获客的性价比，在这个项目初期基本没有自然流量（可能后期也没有，主要和项目策略有关）的时代至关重要（虽然目前广告本身也是大量使用AI生成的）。研发在这之中和美术一样处于需求雕塑的位置。在AI时代之前，不同研发可能因为经验性的差异对项目的推进速度会有比较大的差异，以及可以解决一些技术上的难点；在AI时代之后，推进速度的差异会被放大，许多技术难点会被AI抹平，但是软件本身或者说软件质量的提升对于收益不会有太大了影响，因为AI在不断抬升软件的质量底线（当然还是需要一定的项目管理与需求明确），进一步追求软件质量则显得没有那么具有收益。后端则因为对于用户数据的维护以及对于项目盈利的计算，可能处在一个不那么适合被“插拔”的位置。

说这些和主题有什么关系呢？

在第二段开发经历中，我开始尝试记录并控制自己的开支，但是我发现难以做到。每到周六与周日就会报复性的饮食，周日晚上永远是失眠状态；需要有成本的房租，以及换租之后每到晚上就因为整个公寓共用一根水管管道导致的无法淋浴；日渐堪忧的健康状态以及可能永远也收不到的社保基金。

我用一个月30天，24小时重新计算了自己的时薪——我认为我需要先重新取回自己的时间。

打工无法让储蓄实现质的飞跃，创业则面临着巨大的债务风险；性格成因让我无法维护正常的人际关系，当然也难以从中实现互利。所以我需要先养成健康的金钱观念。

我的父母靠贷款在县城买了房子以及一辆电车，但这并没有让他们更幸福或者富有，农村群体或许大多数都难以适应高密度的网络信息轰炸与过快的生活节奏，成为拼多多和抖音等平台的养料。

”现代人“似乎在接触了城市或者网络之后就难以回到过去，或者说难以主动减少信息获取，但城市化又确实为生活带来了许多便利。就算是在我老家的山沟里，也可以有WiFi，婆婆和爷爷的生活倒是没有因此有很大的变化，他们很长寿。

对于个人而言，或许可以被现代经济拆分成以下三个部分：物质成本与消费、时间成本与消费、信息容量。当然，人们还没有把信息容量当成自己的一种资产，而是不断被互联网厂商抢占的无主资源。Í
